# python 버전 관리에 관한 생각

* 보통은 플랫폼, 라이브러리 제공하는 측에서 사용자를 배려해줘야 하는데 python은 사용자를 전혀 배려하지 않은 느낌.
* 유연하게 여러가지를 제공하다가 고구마 줄기처럼 수습 못 할듯.

# venv
* Python의 **`venv`(Virtual Environment)**
* 시스템에 설치된 Python을 기반으로 하되 프로젝트마다 별도의 패키지 설치 공간을 제공하는 기능
* py 스크립트 하나 실행하고자 별짓을 다해야하는 거지 같은 시스템

# uv
* Python 버전 관리, 패키지 설치, 가상환경 생성, 의존성 관리, 스크립트 실행을 하나로 통합한 도구
* uv는 Python의 구조적 문제를 없애기보다는 사용자에게 노출되는 복잡성을 줄여 주는 도구

## 실행 예시
```bash
uv run --no-project --with bleak scan.py
```
* 사용할 Python 인터프리터 확인
* 필요하면 Python 다운로드
* 격리된 실행 환경 준비
* `bleak` 패키지 설치
* `scan.py` 실행
