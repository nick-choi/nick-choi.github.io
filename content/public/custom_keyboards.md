# Nut65
* 저가형 65 배열 키보드로 가성비가 뛰어나다.
* 몇가지 단점이 있는데
  * 보통 65 배열에서 Fn+ESC는 backtick 인데 이 키보드는 공장 초기화 기능을 한다.
    * 그래서 실수로 공장 초기화가 된다.
  * 나는 RALT, 다음을 Fn으로 사용하는데 이 키보드는 반대로 설정되어있다.
    * web driver 들어가서 매핑을 바꿔줘야한다.
  * 추가로 Fn+RightShift+ESC는 보통 tilde 인데 이 키보드는 DFU 진입이다..
    * 따라서 아무 생각없이 tilde 사용하면 갑자기 키보드가 먹통된다.
    * 키조합을 모르니 여태껏 web driver 사이트 들어가서 공장 초기화 했다.
      * 그러면 위의 RALT, Fn도 다시 바꿔야한다 ㅠㅠ
* 위의 단점으로 인해서 고통받다가 Chatgpt를 이용해서 키매핑이 아니라 펌웨어 소스를 수정해서 통채로 변경하면 위의 단점을 다 보완할 수 있지 않을까 해서 커스텀 펌웨어 작업을 진행했다.
